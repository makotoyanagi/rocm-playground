# ROCm Playground

Exploring AMD ROCm platform and HIP programming model for GPU-accelerated computing.

## Overview
- HIP (Heterogeneous-Computing Interface for Portability) programming
- ROCm runtime and toolchain
- GPU kernel development for AMD hardware
- Performance benchmarking on AMD GPUs

## Structure
```
basics/           - HIP hello world and basic kernels
memory/           - Memory management patterns
optimization/     - Kernel optimization techniques
benchmarks/       - Performance comparison scripts
```

## Prerequisites
- AMD GPU with ROCm support
- ROCm 6.x+ installed
- HIP compiler (hipcc)
